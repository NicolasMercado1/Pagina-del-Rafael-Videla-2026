# Rafael Videla - Campaña a Intendente

## Proyecto
Sitio web de campaña política para Rafael Videla, precandidato a Intendente por el partido de Luis Petri (UCR/PRO, centro-derecha argentina). Ex-jefe de la Policía.

## Estilo Visual
- **Paleta:** Azul marino (#0A2463) como `--primary`, dorado (#FFD700) como accent (`.text-gold`, `.bg-gold`), blanco para fondos
- **Tipografía:** Plus Jakarta Sans (display/títulos), DM Sans (cuerpo), JetBrains Mono (mono)
- **Labels en fondos claros:** Usar `text-amber-600` (no `text-gold`) para contraste legible
- **Labels en fondos oscuros (navy):** Usar `text-gold` libremente

## Páginas
- `/` — Inicio (hero, bio, propuestas cards, stats, quote, CTA)
- `/sobre` — Timeline, valores, galería, testimonios
- `/propuestas` — 6 propuestas detalladas (seguridad, infraestructura, economía, salud, educación, medio ambiente)
- `/unete` — Formulario voluntarios + donaciones + info comité
- `/contacto` — Formulario contacto + datos + horarios

## Componentes clave
- `components/navbar.tsx` (client) — Navbar sticky con menú mobile
- `components/footer.tsx` — Footer con redes sociales
- `components/whatsapp-button.tsx` (client) — Botón flotante WhatsApp

## Contenido en español
Todo el sitio está en español argentino. El slogan es: "El orden, la experiencia y el progreso que tu ciudad merece."
